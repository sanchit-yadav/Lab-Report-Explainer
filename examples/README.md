# Pipeline Input & Output Examples

This directory contains real, reproducible artifacts generated by the AI Clinical Lab Report Explainer pipeline using synthetic patient data.

### Included Artifacts:
1. `sample_input_lipid_panel.pdf`: Synthetic lipid panel report (SRL Diagnostics layout).
2. `sample_output_explanation.json`: Full structured JSON contract emitted by the pipeline (Pydantic schema).
3. `sample_explanation_en.md`: Plain-language English patient explanation with claim-level MedlinePlus citations.
4. `sample_explanation_hi.md`: Plain-language bilingual Hindi translation (हिंदी संस्करण).

> *Note: All sample data uses synthetic, de-identified patient records. No Protected Health Information (PHI) is present.*
